# SmartBuff for Wrath 3.3.5a

**What changed in 3.3e-bags.2**

- **Elixirs and flasks** appear in `/sbm` when carried. Restocking a bottle restores its reminder and use settings.
- **Warlock stone options** appear when you learn their **Create** spells, even with empty bags. When a recipient needs a Soulstone or a weapon needs a Spellstone or Firestone, SmartBuff uses a carried stone. If none is carried, one press creates it; a later press applies it if still needed.
- **Soulstone** uses the existing Self First, class and Additional/Ignore settings instead of a Focus checkbox. **Healthstone** is created only when missing and is never used to heal.
